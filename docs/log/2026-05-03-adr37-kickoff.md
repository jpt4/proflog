## Purpose

ADR-0037 is a separate speculative branch created from ADR-0036 after the direct
core.logic tabling replacement subtrack was closed.

The branch investigates whether this project should carry a project-local
enhanced core.logic overlay before replacing finite-domain fuel arithmetic or
introducing broader miniKanren constraints into Proflog.

## Initial Motivation

ADR-0036 showed that imported relational arithmetic can express fuel stepping
without finite-domain arithmetic, but production callers still use integer fuel.
The open question is whether the project can preserve the public fuel API while
removing hardcoded finite-domain bounds that may block reverse or partial
synthesis.

The same work exposed missing or underexposed miniKanren relations in
core.logic, especially `symbolo` and `absento`. Test-local implementations using
`predc` and `treec` were sufficient for ADR-0036 evidence, but ADR-0037 should
decide whether those belong in a reusable project-local core.logic overlay and
whether other canonical miniKanren features should be imported as well.

## Delegation

A coordinator subagent was started for the broad survey and may spawn subordinate
agents for independent slices:

- miniKanren implementation feature survey;
- core.logic TODO/performance audit;
- Proflog greenfield integration audit.

The local branch scaffold records the ADR boundaries while the delegated survey
runs.

## Guardrails

- Keep production behavior unchanged until evidence justifies a narrower patch.
- Prefer low-risk public relation additions before engine-level changes.
- Preserve nominal logic behavior, fair search, constraint reification, and
  miniKanren semantics.
- Treat raw direct core.logic tabling replacement as closed by ADR-0036.
