# SJAS Proof-Constructor Reachability Audit

Date: 2026-05-25

Branch: `adr-0073-sjas-correspondence-program`

## Purpose

This note addresses the first unresolved question from
[SJAS Tableau Relevance Deep Dive](2026-05-25-sjas-tableau-relevance-deep-dive.md):
which proof constructors actually appear in accepted non-`sjas-axiom`
certificates generated by the current SJAS suite, rather than merely being
encodable by `proflog.willard-sjas-code/proof-symbols`.

This is a representative runtime inventory, not a complete theorem. It covers
the Tableau-0 demo system cases that current tests use as ordinary
non-`sjas-axiom` certificates:

- the Group-2 beta theorem `1 = 1`;
- the non-generated arithmetic theorem `1 < 2`;
- the generated Tableau-0 Group-3 self-consistency theorem.

## Probe

Command:

```bash
lein with-profile test trampoline run -m clojure.main -e \
  "(require '[proflog.willard-sjas-test :as t]
            '[proflog.willard-sjas :as sjas]
            '[proflog.sjas-correspondence :as corr])
   (let [demo-system @#'proflog.willard-sjas-test/demo-system
         system (demo-system :willard-sjas-tableau0)
         cases {:beta (:formula (first (filter #(= :group-two (:group %))
                                               (:axioms system))))
                :lt (sjas/lt sjas/one sjas/two)
                :group3 (:formula (:group-three system))}
         result (into {}
                      (for [[k f] cases
                            :let [p (first (sjas/query-succeeds
                                             system f
                                             {:proof-limit 1
                                              :fuel 96}))]]
                        [k {:proof p
                            :audit (when p (corr/audit-proof-term p))}]))]
     (prn result))"
```

The probe completed successfully in roughly 26 seconds.

## Track 2a Consequences

This probe narrows but does not close the proof-constructor question.

The representative non-`sjas-axiom` certificates do not currently exhibit the
full encodable alphabet. In particular, this probe did not reach procedure-call
constructors such as `pos-call` or `neg-call`, nor general equality/disequality
constructors such as `eq-step`, `neq-close`, or `refl-close`.

It does confirm that the unresolved profile layer is not hypothetical:
`profiled` and `willard-sjas-tableau0` appear in every representative
certificate, and `willard-sjas-arithmetic` plus `sjas-equal` appear in ordinary
beta/arithmetic certificates. Track 2b therefore cannot ignore profile wrappers
or arithmetic closure as merely possible artifacts. It must either:

1. treat profile wrappers as erased proof annotations and prove erasure
   preserves the underlying tableau tree and size accounting;
2. make them explicit primitive proof constructors in the SJAS-side apparatus;
   or
3. replace current certificates with unwrapped object-level proof trees before
   claiming a full correspondence.

The Group-3 proof is closer to the plain tableau core. After wrapper erasure it
uses only `conj`, `witness`, `savefml`, `once-univ`, and `close`, which aligns
with the relevance-matrix hypothesis that ordinary tableau tree structure and
closure are central.

## Remaining Reachability Work

- Check whether any current SJAS tests reach `profiled propositional`,
  `profiled first-order`, equality-triggered calls, or disequality closers.
- Decide whether future reachability probes should become an explicit slow test

## Reflected-Clause Follow-Up

A bounded reflected-clause theorem probe shows procedure-call constructors are
actually reachable in current SJAS certificates. The Tableau-0 demo system has
the reflected clause:

```clojure
(demo x) :- (= x 1)
```

Command:

```bash
timeout 240s lein with-profile test trampoline run -m clojure.main -e \
  "(require '[proflog.willard-sjas-test :as t]
            '[proflog.willard-sjas :as sjas]
            '[proflog.ast :as ast]
            '[proflog.sjas-correspondence :as corr])
   (let [demo-system @#'proflog.willard-sjas-test/demo-system
         system (demo-system :willard-sjas-tableau0)
         theorem (ast/pos-lit (ast/app-term 'demo sjas/one))
         p (first (sjas/query-succeeds
                   system theorem
                   {:proof-limit 1
                    :fuel 160}))]
     (prn {:proof p
           :audit (when p (corr/audit-proof-term p))}))"
```

It returned:

```clojure
(profiled
  willard-sjas-tableau0
  (conj
    (neg-call
      (profiled
        willard-sjas-arithmetic
        (sjas-equal
          (sjas-read-one)
          (sjas-read-one)
          (sjas-bind-done))))))
```

Reachable symbols:

```clojure
#{sjas-read-one
  willard-sjas-arithmetic
  neg-call
  sjas-equal
  conj
  profiled
  sjas-bind-done
  willard-sjas-tableau0}
```

Current classification:

- relevant: `conj`, `sjas-read-one`, `sjas-bind-done`
- unresolved: `neg-call`, `profiled`, `willard-sjas-tableau0`,
  `willard-sjas-arithmetic`, `sjas-equal`
- path-sensitive profile forms:
  - probably irrelevant: outer `willard-sjas-tableau0` wrapper
  - relevant: inner `willard-sjas-arithmetic` wrapper

Track 2b can no longer treat procedure-call constructors as merely possible
because they are in the proof-symbol alphabet. For any correspondence claim
covering reflected clauses, it must decide whether `neg-call` and related
procedure-call constructors are:

1. primitive rules in the selected SJAS deduction apparatus;
2. bounded macro expansions over reflected Group-2b axiom applications; or
3. excluded by restricting the correspondence fragment.

The third option would exclude at least this reflected-clause demonstration
from the covered fragment.
